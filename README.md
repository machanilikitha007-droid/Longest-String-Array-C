# Find the Longest String in an Array

**Author:** M.Likitha

## Description

This program stores five words in an array of strings and finds the
word with the greatest number of characters.

## File

longest_string.c

## Concepts Used

- Array of strings
- Two-dimensional character array
- `strlen()`
- Array indexing
- `for` loop
- Conditional statements

## How to Run

gcc longest_string.c -o longest_string
./longest_string

## Sample Output

Enter 5 words:
Word 1: Cat
Word 2: Elephant
Word 3: Dog
Word 4: Tiger
Word 5: Horse

Longest word: Elephant
Length: 8
